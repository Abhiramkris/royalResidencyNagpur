# Hotel Ashoka Imperial & Banquet, Manish Nagar, Nagpur

Official modern web application for **HOTEL ASHOKA IMPERIAL & BANQUET** (3-Star Hotel & Event Destination in Manish Nagar, Somalwada, Nagpur).

## Overview
- **Location:** Plot No. 191, Jai Durga Society, Manish Nagar, Somalwada, Nagpur, Maharashtra – 440015 (10 mins / 3.2 km from Dr. Babasaheb Ambedkar International Airport)
- **Features:** 
  - 5 Room categories with transparent tariff display and direct booking modal
  - Grand Ashoka Banquet Hall (50–250+ capacity for weddings, receptions, conferences, and birthday celebrations)
  - Dedicated `/gallery` page with event filtering (Weddings, Birthdays, Banquets, Dining, Rooms) and year tags (2026, 2025, 2022)
  - Lightbox photo viewer with direct event inquiry
  - Ashoka Imperial multi-cuisine restaurant & catering
  - Responsive contact & location view with interactive Google Maps and WhatsApp inquiry

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
